# 四策略每日盘后报告：Agent交接说明

**版本基准：2026-11-03 北京时间收盘。**  本文件面向独立交叉验证 agent。不要把本说明、其他agent的回测收益或旧报告当成最新行情；须重新抓取、独立计算并披露数据缺口。只输出条件化模拟计划，不连接券商、不自动下单。

## 1. 用户目标与约定（最新用户指令优先）

每个交易日盘后按当日T信号，规划下一个交易日T+1；两种模式：

- **账本一：连续模拟**。T=2026-11-03为起始信号，最早11-04按条件尝试买入。四套策略各自独立20万元、起始空仓，各有现金、持仓、成本、买卖、收益，不能用其中一个账户的资金或仓位影响另一个。不能提前记成交，不可漏过交易日；未查询的交易日应补齐数据和模拟成交，无法核实标待核验。
- **每日独立账本**。每次查询时四套策略各自独立假设20万元、空仓，从当日重新计算次日计划；不继承以前的盈亏和持仓。实际真实持仓另行跟踪，不得因模拟重置而假称已清仓。

费用统一：**买入佣金0.01%、卖出佣金0.01%；其他税费暂不计**；未提供最低佣金，当前模拟假设无最低额。与策略附件原先费用口径有意不同，不是实际净收益。价格滑点保留策略3研究用单边0.05%、策略4单边0.1%；其他策略没有明确设置则不编造。开盘或收盘日线价仅作模拟参考，不代表真实可成交。买入日A股T+1不可卖；停牌、涨跌停、缺失和除权均要处理。

## 2. 文件结构与快速启动

压缩包根目录：

```
README_给Agent.md                  # 本说明
stock_pool/account_config.json     # 用户确认的资金/账户/策略设置
stock_pool/strategy1/strategy1_universe_969.csv
stock_pool/reconstructed/          # 独立实现、两份冻结股票池、单元测试
stock_pool/data/prices/            # 85个交易日通达信原始日线CSV，2026-06-30至11-03
stock_pool/ledger/                 # 连续账本初始化及当日独立预案；无成交
stock_pool/reports/                # 11-03计算、候选、数据/席位快照和限制说明
原始附件/                           # 用户给的三份原策略和策略1名单
```

Python 3.10+（建议3.11），依赖 pandas、numpy、requests。可选 openpyxl 仅用于查看/编辑xlsx。无交易API或账号密码：

```bash
python -m pip install pandas numpy requests openpyxl
cd stock_pool/reconstructed
python -m unittest -v
python run_daily.py                          # 北京时间最近一个完整收盘日
# 或 python run_daily.py --asof 2026-11-03  # 历史复核，某些接口仅当日可核价
```

`run_daily.py`先获取可用交易日与通达信包、计算策略1、2、3、复核3当日限价，再以 `longhu_independent.py`独立调用东方财富抓取策略4。**不读取longhu仓库生成的报告/账本，也不需要仓库自身运行成功。** Sina/TDX/东方财富依赖外网、可能失败或更新；失败不等于无信号。策略4披露两次抓取间隔15秒，结果仍可能后续变化。

输出在 `stock_pool/reports/`：`daily_run_YYYYMMDD.json`（步骤状态）、`v3_prefilter_YYYYMMDD.json`、`tdx_prefilter_YYYYMMDD.json`、`bf_limit_audit_YYYYMMDD.json`、`longhu_independent_status_YYYYMMDD.json`及席位明细/源快照。`ok`只表示程序未异常，不证明行情全市场完整、各规则精确或有真实成交。

这些脚本可用于独立数据核验，但**不是完整的每日交易账本引擎**。`ledger_engine.py`仅能在调用方已经核验成交事件后记手工/模拟买卖，不能自行判断策略的完整开仓、卖出或重放；也不是经核验的真实账户。agent应继续实现并测试状态转移，不得声称后台已自动记账。

## 3. 策略编号与冻结规则

### 策略1｜V3动量＋突破

依据 `原始附件/final_report_v3 (1).html`，固定名单为用户提交的969个代码 `stock_pool/strategy1/strategy1_universe_969.csv`，不是从历史交易明细倒推；CSV代码作为字符串读取，防止前导0被删除。经2026-11-03行情核验969个唯一六位代码与名称匹配。平均成交额单位万元，计算周期未提供；不用于替代每天实时行情。

- 沪深主板、固定969名单、信号日非ST，停牌/数据缺口明确标注；任一触发：涨幅>2%且成交量>此前5日均量×2；收盘≥此前60日最高收盘且量>此前60日均量×1.5；同突破且量>此前60日均量×1.2。
- 按命中条数降序、信号日涨幅降序；最多5只、等权；次日开盘过滤高开>6%、低开<−5%、涨停/停牌；固定持有2个交易日后开盘卖出，一字跌停顺延。当前重建采用“此前60日不含信号日”且跨日可比复权价；原代码未提供，须披露该假设。
- 沪深300收盘低于含当日的MA20时不开新仓；门控不决定旧仓退出。

### 策略2｜S2标准5日

依据 `原始附件/S2扫描器说明.md`；用户要求保留观察：附件报告长周期表现为负，近两年较好不保证未来有效。**用户明确要求不再考虑首板日历史股本、首板日市值**；仍保留附件序言中的信号日总市值严格<300亿元，须校验同日来源/时间。不要以今日股本回算首板市值，也不要假称已查历史股本。

- 首板涨幅≥9.85%，前一日未涨停，前10个交易日无涨停，首板成交量≥前5日均量×2；次日未涨停且涨幅≤5%、成交量≥首板量×0.8。
- 随后5日调整：平均量≤分歧量×0.6、对数成交量回归斜率<0、每天收盘≥首板收盘×0.97（相同复权基准）；调整后3个交易日内，首次收阳且量≥调整均量×1.5的T，其涨幅≥2%才是有效信号。T+1开盘价≥T收盘×1.0985则跳过。
- 规则规定持有2日，盘中跌破买入价−5%止损，收盘跌破首板×0.97支撑退出，第二日收盘到期；需逐笔结合A股T+1、涨跌停/停牌，无法当日卖时不能伪记成交；盘中触价不保证止损价成交。说明文字对持有期口径、缺失/停牌及止损价的细节未给出完整代码，需验证并明确假设。
- 用户新增模拟组合：最多4只；可用现金按当前空位等分、每笔成交后重算；同日候选按T日涨幅从高到低，平手代码升序。此规则不是原回测规则。

### 策略3｜BF＋G3＋Tail1000－3050版

完整基本反包、评分、流程与退出见 `原始附件/BF_G3_Tail1000_strategy.md`。**用户已修改市场指数池**：采用 `stock_pool/reconstructed/bf_index_universe_3050_20261103.csv` 固定成分，不再是原版3297清单。3050基于11月3日名称非ST初步名单，含当日停牌、退市整理和新股等可能不合规个股作为指数成分；指数的当日收益仍仅用有效交易且可比较上一市场交易日收盘的股票。该名单永远固定、不自动跟踪后续新股或ST变化，直到用户另行指示；历史时点若该成分曾是ST，指数可包含该时点ST。利用今日名单回算过去表现可能有幸存者偏差，不可沿用原回测收益宣称改良。

个股**买入候选池**独立于指数池，按附件动态条件：沪600/601/603/605、深000/001/002/003；T非ST、有效交易、≥60根有效日线、未复权收盘≥3元、T−20…T−1完整均额≥3000万元、已明确退市/无交易资格不买。买入日再核交易状态；停牌不向前填数据。实际涨跌停价优先，普通非ST主板PC×110%/90%按分四舍五入可推算，但特殊IPO/除权/制度例外不可强套；收盘/触板容差0.001元。跨日价格比较用同一复权口径。

I由3050成分的当日不复权C/C前一市场日−1裁剪到±11%后等权累计；BF门控I(T)≥MA20(T)。基础反包：T收盘涨停、T−1收阴或触板未封、T−6…T−2至少一次收盘涨停、复权T收盘严格高于复权T−1开盘和收盘两者最大值。打分ZT1（窗口恰一次）、LIQ25（此前20日均额≥2.5亿）、NODG（T开盘≥PC）：3分A、2分B。原始集中存在A就只用A，决不因A后续无法买退级到B；同池按此前20日均成交额S降序、平手6位代码升序。

BF先检查市场门控、S≥2亿、T−1不是触板未封、T+1高开不超过8%、非持有、买入日可交易且非开盘涨停；有可执行BF候选即BF路线，不因后续预算不足切G3。A池每日最多2、B池最多1；无BF合格候选或市场不允许才走G3（仍同一P池，无BF额外四项），G3同时最多1只、单票含费预算≤5万元且买后留10万元。策略共最多4只、每日最多新买2只、不可重复持有。BF每笔预算=min(10万元,max(0,cash−max(0,4−当前持仓数−1)×1000))，逐单重算。佣金使用用户覆盖的万1/边，最低佣金暂不设。

买入当日不卖；下一市场交易日收盘起评估：停牌/无有效收盘/收盘跌停继续等待不加顺延；收盘涨停且顺延<3则加1继续持有；否则该日收盘尝试退出，累计顺延达到3后不再因涨停顺延。日线中以最终收盘价判断并同价成交是研究近似，不能提前声称已知最终收盘状态。

### 策略4｜龙虎榜机构席位

按 `https://github.com/huvan9527-a11y/longhu` 的规则**自主抓取并运行**，不要依赖该仓库已有报告、Actions是否运行或旧账户。请读取 `stock_pool/reconstructed/longhu_independent.py`，它独立请求东方财富 `RPT_DAILYBILLBOARD_DETAILS`、`RPT_BILLBOARD_DAILYDETAILSBUY`、`RPT_BILLBOARD_DAILYDETAILSSELL`，按独立披露组核对席位数量，间隔复查，错误隔离且报告；收盘披露仍可能持续更新。

- 0/6开头、排除ST，T收盘涨幅≥5%；任一当日披露卖出席位出现机构专用即排除。
- 0开头：同一机构专用买入席位的买入额严格>2000万元且该席位卖出额=0；不把多席位金额拼凑。
- 6开头：同一独立披露机构专用买入额合计严格>2000万元；不同披露原因不跨组合计。同股票同日最多1条信号，重复席位无法辨认则隔离。
- T+1开盘尝试买入，开盘涨停、跌停、停牌不成交；单笔含费投入≤下单前总资产1/3，不补仓。研究参考单边0.1%不利滑点，佣金按用户新设万1。买入后的下一个交易日收盘尝试全部退出；停牌、收盘跌停继续等待。文档提及板块数量限制但没有明确全部数值，不自行捏造。

## 5. 独立核验须知

1. 新交易日重新确认交易日历、数据截面、复权、日线、交易状态、ST及真实涨跌停，尤其不能用今日盘口反推历史实际限价；S2若有形态候选，核查同日总市值。
2. `market_data.py`从通达信官方日包取未复权行情；不同源复核价与市场指数。`bf_index_3050.py`只用上一市场日而不是上一有成交日，停牌不填充。
3. 本包的脚本已经跑过17项小型单元测试，不代表历史回测、交易仿真、限价和成本等都已验证。S2原代码未提供；策略1 60日窗口及部分交易细节需要明确。
4. 连续模式要保证时序和不可重放：未确认的条件单不入持仓；跳过未查询交易日时要补齐、记录数据来源和每笔事件；同一事件幂等、现金和股票不超限。独立模式每天重置不得反过来修改连续账本。
5. 数据不足必须列“未核验”，不可用“无信号”掩盖；两份Agent结论不同需对齐股票池、复权、成交额窗口、市场门控、费用、交易日与龙虎榜披露时点后解释。
