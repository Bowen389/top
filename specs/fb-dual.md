## 0. 策略一句话

> 每天收盘后找"10cm 主板首板（涨停且昨日非涨停）+ 成交额≥1亿 + 指数<MA20"的股票；次日开盘按缺口与位置分两类买入（深低位板 C2 优先，普通低位板 C1 其次），最多持 4 只、每只 1/4 仓位；买入次日收盘无条件卖出（跌停/停牌顺延）。

## 1. 数据依赖（全部为日频公开数据，无分钟数据需求）

| 数据 | 用途 | 精度要求 |
|---|---|---|
| 全市场日线 OHLC + 前收盘 + 成交额 + 停牌状态 | 信号与执行 | 交易所口径，前收盘须为**除权调整后**的官方前收盘 |
| 复权收盘序列（个股） | pos60_med | 任何内部一致的前/后复权序列均可（复权锚点不同只差一个常数，比值不变），但窗口内必须同一序列 |
| 中证1000 指数（sh000852）收盘 | 大盘过滤 | 价格指数即可 |
| 股票名称（含 ST/退 标记） | 排除 | 当日名称 |

**口径定义（与回测逐字一致）：**
- `ref` = 当日官方前收盘（除权调整后）；`gap` = `开盘价 / ref - 1`（= 交易所意义的开盘缺口）。
- `adj_close` = 复权收盘；`pos60_med = adj_close(T-1) / median(adj_close(T-60..T-1))`，共 60 个交易日，**不含 T 日**。
- `money_t` = **T 日（板日）成交额（元）**。
- `B_MA20`：`idx_close(T) / mean(idx_close(T-19..T)) - 1`，均线**含 T 日**。
- 涨停/跌停判定：限价 = round(前收盘 × 1.10, 2)（主板 10%）；判定容差 0.005 元。停牌日无信号。
- "首板"：T 日收盘价触涨停（容差内）**且 T-1 日收盘未触涨停**（T-1 停牌按未涨停处理）。

## 2. 股票池（T 日收盘时判定，全部满足才进入候选）

1. 沪深主板 10% 板股票（代码 sh60/sz00 系）。**创业板（300/301）、科创板（688/689）、北交所一律排除**（现行 20cm 板自然不满足首板+gap 条件，硬排除更保险）。
2. 股票名称不含 `ST`、`退`（T 日名称快照）。
3. 上市 ≥ 120 个交易日。
4. T 日有成交（非停牌）。
5. **T 日成交额 ≥ 1 亿元**。
6. T 日非开盘即涨停（T 日开盘价 < 涨停价，容差 0.005 元；一字板由此排除）。

## 3. 信号（T 日收盘后计算）

按顺序过滤，全部通过 → 记为"候选"：

1. §2 全部满足；
2. **首板**（§1 定义）；
3. `pos60_med` 计算有效（不足 60 日历史 → 无信号）且 **pos60_med < 1.0**；
4. **大盘过滤：`B_MA20 < 0`**（中证1000 收盘低于其 20 日均线）。不满足 → **当日全体无信号**（此过滤是全体性的，不是逐股的）。

## 4. 入场决策（T+1 开盘，此刻才最终决定买不买）

### 4.1 缺口分类（互斥矩形，其他一律不买）

```
gap = T+1 开盘价 / T 收盘价(除权调整后) - 1     ← 开盘竞价出结果后立即计算

若 pos60_med < 0.7  且 -2.5% ≤ gap ≤ +5.0%   → 类别 C2（优先级高）
若 0.7 ≤ pos60_med < 1.0 且 -5.0% ≤ gap < -2.0% → 类别 C1
其他任何情况                                  → 不买（包括 pos<0.7 且 gap<-2.5%、
                                                    pos<0.7 且 gap>+5%、
                                                    pos 0.7~1.0 且 gap≥-2% 或 gap<-5%）
```

- **注意缺口上下沿的不对称**：C2 的 −2.5% 是下限（更深低开不买，尾部=连续跌停），+5% 是上限（更高开不追）；C1 的 −5% 下限同理，−2% 上限用于排除浅低开/平开。
- 边界按回测口径执行：两个窗口**都是双端含**——C2 窗口 [−2.5%, +5%]、C1 窗口 [−5%, −2%]；gap 恰为 −2.00% 时按 C1 买入（须 pos∈[0.7,1.0)）。两窗口由 pos 区间互斥，无重叠。

### 4.2 不成交与作废

- T+1 停牌 → 不买，信号作废（不顺延、不追）。
- T+1 开盘价 = 涨停价（容差内，一字涨停开）→ 不买，信号作废。
- gap 不可得（数据异常）→ 不买。

### 4.3 队列与槽位（同日多信号时）

排序：**先 C2 后 C1；同类内 gap 升序（低开多的优先）；再按代码升序**。（已验证排序敏感性 <5%，此顺序冻结。）
循环处理队列，每只股票检查：

1. **总持仓槽未满 4**（含今日已买入的）；
2. 该股当前无持仓（同代码不重复持有，不加仓）；
3. 现金足够（见 4.4）；
→ 买入。否则跳过该信号（不顺延到次日）。

### 4.4 仓位与资金

```
每笔预算 = min( 当前权益/4 × 0.99 , 可用现金 × 0.99 , T日成交额 × 0.1% )
买入股数 = floor(预算 / 买入价 / 100) × 100        ← 整手，100 股
买入价   = T+1 开盘价（实盘以开盘竞价实际成交价为准）
买入费用 = 佣金 max(成交额 × 0.025%, 5元)
```

- "当前权益" = 现金 + 持仓按最近收盘复权口径估值（见 §7）。
- 股数不足 100 股（预算太小）→ 跳过该信号。
- 全部买入以**开盘竞价（09:15–09:25 挂单，09:25 成交）**完成；不得盘中追单。

## 5. 退出（无条件、无判断）

1. **T+2 收盘卖出全部当日到期持仓**（执行：14:57 后以收盘竞价/市价卖出，或以当日收盘价成交）。
2. **卖不出则顺延**：若 T+2 收盘跌停（收盘价=跌停价±0.005）或停牌 → 改为下一个"可卖收盘"（当日有成交且收盘非跌停）卖出。**实盘持有至卖出为止，永不放弃持仓**；回测统计口径顺延 >8 个交易日标"未完成"仅用于归因，实盘无此概念。
3. 卖出费用 = 佣金 max(成交额 × 0.025%, 5元) + 印花税 成交额 × 0.05%。
4. **禁止**：止损、止盈、提前卖出、延长持有、盘中卖出。唯一卖出时点是"到期后的第一个可卖收盘"。

## 7. 记账与净值

- 持仓估值 = `买入成本 × adj_close(今)/adj_buy`（复权口径，与回测一致，含分红再投资效应）。
- 每笔成交必须记录：`code, class(C1/C2), board_date_T, buy_date, buy_price, units, gap, money_t, pos60_med, B_MA20, sell_date, sell_price, deferred_days, fees, net_profit, status`（字段见 strategy_config.json）。
- 月度对账一次：持仓、现金、费用与逐笔记录勾稽一致。

## 8. 风控与停机（唯一允许的"主观"动作是停机，不允许改规则）

**触发任一条件 → 停止开新仓**（存量持仓仍按 §5 退出纪律执行），并通知策略所有者：

1. 滚动 12 个月**事件均值**连续 3 个月末 < 0。事件均值定义：把当月所有通过 §3 的候选（无论是否成交）按"次日开盘买→次日收盘卖、基准费用（佣金万2.5+印花税+滑点千1/边）"计算净收益，滚动 12 个月求均值。低于 −0.2%/笔 即为警戒线以下。
2. 组合净值自历史高点回撤 ≥ 35%。

恢复条件：均值连续 2 个月末回升至 0 以上且回撤 < 25%，由所有者书面确认后恢复。
**永不允许**：改阈值/槽数/排序/窗口、加杠杆、加仓摊低、跳过信号、按盘感否决。
