# S2「标准·5日」信号扫描器 — 使用说明

> ⚠ **风险提示**：长周期验证（2019-03 ~ 2026-11）显示 S2 整体为负期望。全样本总收益 -26.6%，样本外前段（2019-03 ~ 2024-10）-36.5%，单笔均收益 -0.49%。两年期的正收益不具稳健性。本扫描器只做规则复现与信号列示，**不构成投资建议**。

## 1. 它做什么

每个交易日收盘后，扫描沪深主板（非ST、信号日总市值 < 300 亿）全部股票，找出按 S2 规则在**今日收盘确认**的再启动信号，供次日开盘关注。

## 2. S2 规则（与回测代码逐条一致）

| 环节 | 规则 |
|---|---|
| 首板 | 涨幅 ≥ 9.85%（涨停），前一日未涨停；前 10 个交易日内无涨停；首板量 ≥ 前 5 日均量 × 2；收盘价 × 总股本 < 300 亿 |
| 分歧 | 次日未涨停，涨幅 ≤ 5%，成交量 ≥ 首板量 × 0.8 |
| 调整（5 日） | 调整期均量 ≤ 分歧量 × 0.6（缩量）；调整期成交量对数回归斜率 < 0（大致趋势）；调整期每日收盘 ≥ 首板收盘 × 0.97（支撑） |
| 再启动 | 调整结束后 3 个交易日内，首次出现"收阳 且 成交量 ≥ 调整期均量 × 1.5"的交易日 T；T 的涨幅 ≥ 2%（L1–L3，不含 L4） |
| 买入 | T 的次日开盘买入；若开盘 ≥ T 收盘 × 1.0985（涨停附近）则放弃 |
| 退出 | 持有 2 日；盘中跌破买入价 -5% 止损；收盘跌破支撑价（首板收盘 × 0.97）退出；第 2 日收盘到期 |

## 3. 运行方式

```bash
cd ~/quant
python3 scan_s2.py            # 抓取最新数据（新浪，约数分钟），扫描并写入 signals/
python3 scan_s2.py --json     # 同上，并把 JSON 打印到标准输出
python3 scan_s2.py --no-fetch # 使用上一次抓取的 data/scan_latest.pkl，不联网
python3 scan_s2.py --selftest # 自检：与回测事件表对照，须输出"一致 ✅"
```

**运行时间**：建议在收盘后（15:00 之后）运行，否则当日 K 线可能不完整。

## 4. 输出

| 文件 | 内容 |
|---|---|
| `signals/s2_YYYYMMDD.csv` | 今日 TRIGGERED 信号（T = 数据最后一个交易日），含首板、分歧、调整指标、支撑价、买入计划 |
| `signals/s2_YYYYMMDD.json` | 同上，JSON 格式，字段含 `as_of`、`triggered[]`（代码、名称、T 日期、涨幅、分层、支撑价、买入计划） |
| `signals/s2_watch_YYYYMMDD.csv` | 观察名单（状态 WAIT）：调整已完成，仍在 3 日再启动窗口内等待放量收阳 |

JSON 示例结构：

```json
{
  "as_of": "YYYY-MM-DD",
  "strategy": "S2 标准·5日",
  "warning": "长周期验证为负期望，输出仅为规则复现，不构成投资建议",
  "triggered": [
    {"code": "600000", "name": "...", "trig_date": "YYYY-MM-DD", "tier": "L3",
     "trig_pct": 3.2, "trig_close": 10.5, "first_date": "...", "first_close": 9.8,
     "support_price": 9.5, "plan": {"buy": "...", "stop_loss": "...", "support_exit": "...", "time_exit": "..."}}
  ],
  "watch_count": 12
}
```

## 5. 给调用方（其他 agent）的注意事项

- 若 `triggered` 为空，表示今日无信号，**不要**凭空补充。
- 必须在输出中保留风险提示，不要把信号描述为"推荐买入"。
- 买入以次日开盘价为准，信号中的价格仅为 T 日收盘参考。
- 股票池的 ST 标记与总股本来自 `data/universe.csv`，该文件是较早时点的快照。ST 状态变化和股本变动不会自动更新，长期使用前应重新生成。
- 信号依赖新浪前复权数据；数据源故障时脚本会报告抓取失败数量，结果可能缺漏。

## 6. 文件

- `scan_s2.py`：扫描器主程序
- `data/universe.csv`：股票基本信息（代码、名称、ST 标记、总股本）
- `data/scan_latest.pkl`：最近一次抓取的日K缓存
- `signals/`：输出目录
- `backtest.py`、`long.py`：回测代码（规则来源）
