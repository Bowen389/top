## 0. 策略一句话

每天收盘后从龙虎榜中筛选「机构专用席位真金白银买入」的股票，剔除三类有害信号后形成带等级的名单；次日开盘确认后等额买入；再下一个交易日收盘无条件卖出。短周期事件驱动，不预测涨跌，只执行清单。

## 1. 数据源（必须按此获取）

全部来自东方财富公开接口，UA 用普通浏览器字符串，Referer 设 `https://data.eastmoney.com`。

**1a. 龙虎榜披露（T 日 17:10 后获取，翻页拉全）**

| 用途 | reportName | 说明 |
|---|---|---|
| 榜单概览 | `RPT_DAILYBILLBOARD_DETAILS` | 每只股票当日一行：涨跌幅、换手率、收盘价、上榜原因、类型 |
| 买入席位明细 | `RPT_BILLBOARD_DAILYDETAILSBUY` | 每席位一行：营业部名称、买入额、卖出额 |
| 卖出席位明细 | `RPT_BILLBOARD_DAILYDETAILSSELL` | 同上 |

接口：`https://datacenter-web.eastmoney.com/api/data/v1/get`，参数：
`reportName=<上表>&columns=ALL&pageSize=500&pageNumber=<n>&sortColumns=TRADE_DATE,SECURITY_CODE&sortTypes=1,1&filter=(TRADE_DATE>='YYYY-MM-DD')(TRADE_DATE<='YYYY-MM-DD')`，按返回 `pages` 翻页拉全。

**1b. K 线（用于开盘确认，T+1 盘中或盘后）**

`https://push2his.eastmoney.com/api/qt/stock/kline/get?secid={市场}.{代码}&klt=101&fqt=0&beg=YYYYMMDD&end=YYYYMMDD&fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61`
- secid：代码以 **0 或 3 开头 → `0.代码`**；**6 开头 → `1.代码`**（fqt=0 不复权）。
- 行格式：`日期,开盘,收盘,最高,最低,成交量,成交额,振幅,涨跌幅,涨跌额,换手率`。
- 交易日历：用上证指数 `secid=1.000001` 的日 K 日期序列判定交易日。

**1c. 时间约定**：所有日期指 A 股交易日；「T 日 17:10 后」指北京时间。非交易日不产生信号。

## 2. 基础信号（T 日晚间，逐步执行）

对 T 日的榜单数据执行：

```
S1 板块     : 仅保留代码以 0 或 6 开头的股票（排除创业板3、北交所等）
S2 ST       : 证券简称含 "ST"（含 *ST）的剔除
S3 涨幅     : 当日涨跌幅 ≥ 5%（用榜单 CHANGE_RATE，单位 %）
S4 卖出席位 : 卖席位明细中存在营业部名称含 "机构专用" 的行 → 该股剔除（一条都不许有）
S5 机构买入（按板块二选一）：
   0开头 : 恰好 1 个"机构专用"买席位，且该席位买入额 > 20,000,000 元，且该席位卖出额 = 0
   6开头 : 所有"机构专用"买席位买入额之和 > 20,000,000 元（卖出额不作要求）
S6 合并     : 同一 (日期, 代码) 当天多条披露（单日+多日榜）→ 合并为 1 条信号
S7 交易日   : K 线显示 T 日停牌/无成交（成交量=0）→ 剔除
```

记通过 S1–S7 的信号为 **基础信号**。关键字段：
- `qualifying_amount` = S5 中参与比较的买入额（0开头=单席位买入额；6开头=机构买入合计）
- `涨幅` = CHANGE_RATE（%）；`换手率` = 概览 TURNOVERRATE（%）
- **上市日期记 T，信号于 T 日晚间产生，买点在 T+1 日开盘，卖点在 T+2 日收盘**（T、T+1、T+2 为连续交易日序列，遇节假日顺延至下一交易日）。

## 3. 过滤与等级标注（T 日晚间，对基础信号）

```
F1 剔除涨幅 7-9% 档 : 7% ≤ 涨幅 < 9% 的信号剔除（其余一律保留，含 <7% 和 ≥9%）
F2 剔除 1 日内重复  : 代码出现在 T-1 交易日的基础信号名单中 → 剔除
                      （注意：与 T-1 比较的是"基础信号"而非过滤后名单；
                        同日多披露合并的不算重复，只有跨相邻交易日才算）
F3 换手率条件（仅非 0 开头）:
   0 开头 : 不要求换手率
   非 0 开头 : 换手率 > 10% 才保留，否则剔除
```

对通过过滤的信号打标签（唯一分类，互斥）：

| 标签 | 条件 | 历史单笔均值 | 单票仓位上限（占总资产） |
|---|---|---:|---|
| **★N1+N3** | 0开头 且 换手率>10% | +2.41% | 1/2 |
| **★N1** | 0开头 且 换手率≤10% | +0.61% | 1/2 |
| **N3** | 非0开头 且 换手率>10% | +1.10% | 1/3 |

三类**全部执行**。无信号日为空仓等待，属正常状态。

## 4. 次日开盘确认（T+1 开盘，必做，逐只判定）

对名单中每只股票计算：**开盘涨幅 = (T+1 开盘价 ÷ T 日收盘价 − 1) × 100%**

```
开盘涨幅 < -5%                    → 放弃不买（深低开接飞刀，历史胜率仅 33%）
T+1 开盘价 ≈ 涨停价（一字板）       → 放弃不买（无法成交）
   判定：开盘涨幅 ≥ 涨停幅-0.2pct（10% 板取 9.8%，688 取 19.8%）
开盘涨幅 ≥ +6%                    → 照常买入（高开是顺势信号，历史胜率 69.6%，禁止因高开放弃）
其余（含 -5% ~ +6%）              → 执行买入
```

**取不到 T+1 开盘价（数据未更新/停牌）→ 放弃，不得凭盘中价追买。** 确认动作应在开盘后 30 分钟内完成。

## 5. 买入执行（T+1 开盘）

```
B1 方式 : 限价单，限价 ≤ 开盘价 × 1.005（不得追高超过开盘价 +0.5%）
B2 金额 : 等额买入 —— 每只股票投入相同金额
          每票金额 = 总资产 × 50% ÷ 当日执行只数
          且单票金额 ≤ 总资产 × 标签上限（★N1 系 1/2，N3 1/3）
B3 条件 : 开盘后 30 分钟内未成交（或价格已涨过限价）→ 撤单放弃该笔，不追单
B4 禁止 : 不买名单外股票；不加仓已持有股票；不用杠杆
```

## 6. 卖出执行（买入日的下一交易日 = T+2）

```
默认 : T+2 收盘无条件全部卖出（市价单，收盘竞价执行）。不设止损，不设预期止盈。
可选变体（二选一，选定后不再更改）:
        持有期内盘中价 ≥ 买入成本 × 1.15 → 挂条件单卖出；
        未触及则 T+2 收盘无条件卖出。
```

卖出资金当日可用，回到下一信号循环。

## 7. 边界情况速查

| 情况 | 处理 |
|---|---|
| 名单为空 | 当日不交易，正常 |
| 同一代码同日多条披露 | 合并为 1 条信号（不是重复） |
| 同一代码连续两个交易日都有信号 | 只执行 T 日那条，T+1 的重复信号剔除（届时已持仓，也无资金重复买） |
| T+1 一字板/停牌 | 放弃该笔 |
| T+1 开盘数据取不到 | 放弃该笔 |
| 基础信号全被过滤 | 空仓，正常 |
| 非交易日/节假日 | 一切日期按交易日历顺延，无信号 |
| 数据接口翻页不全 | 必须按 pages 拉全再筛，宁可当晚不出信号，不许用残缺数据 |

## 8. 每日标准作业流程（SOP）

```
T 日 17:10–24:00 : 拉 1a 三表（T 与 T-1 两天）→ §2 基础信号 → §3 过滤+标注 → 输出名单存档
T+1 日 09:30–10:00: 拉 1b 开盘价 → §4 开盘确认 → §5 买入 → 记录成交明细
T+2 日 14:55–15:00: §6 全部卖出 → 记录
每日              : 记录信号数、标签、买入/放弃原因、成交与卖出价，存为台账 CSV
```

参考实现（可直接复用或照抄逻辑）：`/home/user/longhu_bt/screen_n3.py`
- 晚间：`python3 screen_n3.py [日期]` 出带标签名单
- 开盘：`python3 screen_n3.py check [信号日]` 出逐只 买/放弃 判定

## 9. 资金与监控纪律（严格执行，不许临场变通）

- **前 3 个月用总资金的 1/4 实盘验证**，达标后才加到全量。
- 月度必核三个数：执行笔数（预期 8~10 笔/月）、单笔均值（应 ≥ +0.5%）、★N1 级命中次数。
- **连续 2 个月单笔均值为负 → 停止交易**，复查数据抓取与执行是否有偏差（而不是调整规则）。
- 永久禁止：加止损/移动止盈（默认变体外）、改过滤阈值、按盘中走势临时决定、跳过开盘确认、买名单外的票。
- 市场状态提示：本策略在单边普涨牛市中会退化（样本外牛市年均值降至 +0.2%），若指数连续大涨且策略持续跑输，属已知行为，减半仓位继续执行，不改规则。
