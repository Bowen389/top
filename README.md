# 六策略盘后工作包

北京时间每个交易日约 17:00 启动，先扫描两套龙虎榜，再扫描其他四套策略。龙虎榜披露尚未齐全时标为待核验，17:10 优先补扫，19:05 再核验。GitHub Actions 的排队和数据源更新会影响报告时间。交易日由上交所日历确定，行情必须对应当天。Actions 页面支持手动运行当天任务。

- [最新日报](reports/latest.md)和 `reports/YYYY-MM-DD.md` 提供逐策略候选及次日开盘条件，日期 JSON 保留信号因子和数据核验状态。
- [逐笔信号台账](reports/signals.csv)记录信号标识、开盘缺口、模拟买卖、跳过与顺延原因、价格、股数、费用和净盈亏。当天未核验的数据标为待核验，区别于成功扫描但无候选。
- [模拟账户](reports/book.json)保存现金、持仓及事件历史。各策略独立从空仓、20万元起步。两份独立手册未规定模拟本金，沿用交接包的20万元。原始策略规范在 [specs](specs)。
- 原四策略保留交接包费率和滑点。FB 使用其规格佣金与印花税。N3 采用默认到期收盘退出、双边万一佣金作为模拟假设。

## 行情和成交口径

工作流使用新浪指数、通达信日包和东方财富披露及报价。逐笔模拟用当天收盘后可核验的日线还原开盘和收盘，所有策略均无券商接口。N3 的开盘价模拟无法核验 30 分钟挂单是否实际成交。S2 使用日线最低价触发止损，跳空时按开盘参考价，价格和撮合顺序属于近似。BF 历史普通主板限价按参考前收盘推算，当前候选另外核验。

FB_DUAL_K4 文档内 C1 的 −2% 以明确写出的双端包含说明为准。滚动 12 个月事件风控需要另补历史事件，仓位模拟目前执行组合回撤暂停。附件中只有文字规格，没有随附的 19 个黄金用例，尚无法完成该规格的验收。N3 的月度停机与人工验证条款留作人工监控。以上输出用于研究和纸面核对。
